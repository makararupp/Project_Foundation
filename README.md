# SOTHEARITH Foundation (Vue 3 + Vite)

Static website. Requires Node.js 18+.

```bash
npm install
npm run dev       # local dev server (http://localhost:5173)
npm run build     # outputs static site to /dist
npm run preview   # preview the production build
```

- Edit text/links in `src/data/content.js`
- Edit styles/colors in `src/assets/main.css` (CSS variables at the top)
- Each page section is a component in `src/components/`
- Deploy the `dist/` folder to Netlify, Vercel, GitHub Pages, or Cloudflare Pages
